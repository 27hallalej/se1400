Axa Linux

This linux distro is a personal project of mine. It's about halfway done now, and will be open to the public by around mid-summer. I'm making my own init system, package manager, and window manager, all to test my Linux knowledge.

What is Axa Linux?

It's an "ecosystem" of different products (the distro, the init system, the package manager, etc.) that adheres to three main principles:

  • Open-source, no-license software
  • Suckless (minimalistic) code
  • Extensive language compatibility

Opaline and Bfly

Opaline is a simple encryption software that turns files into images and videos. There's a video online that showcases it, but it's not going to sound or look pretty since it's just the raw data forced into a video. Still entertaining.

It's written in Python, and has a github repository available.


Similarly, bfly is an encryption algorithm that uses zipf's law to encrypt data. You input plain text documents (like the ones you can find on Project Gutenberg), and it will count how many of each word is present in the text or texts you input.

Then, it attributes simple chunks of bits which are inversely proportional to the number of instances of each word, such that common words like "the" will have a low bit value (like 10) and complex words like "obsequious" would have a high bit balue (like 110101).

These bit values then become the seed for a series of pseudo random number generators which scramble your precious data.

It's coded in Rust, and is not available to the public yet.
